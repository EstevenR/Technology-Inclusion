# Frontend de Technology Inclusion

Aplicación web desarrollada con React, TypeScript, Vite, Tailwind CSS y shadcn/ui.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
```

La salida de producción se genera en `dist/`. Consulta el [README principal](../README.md) para conocer la estructura completa y las instrucciones del backend y del despliegue.
